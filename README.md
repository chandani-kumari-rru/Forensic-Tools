# Forensic-Tools

## Forensic Imaging
| Download      | Forensic Tools    | Description
| ------------- | ----------------  | ----------------------------------------------------------------------------------------------------- |
| [Click]()     | dd                | A standard Unix utility for copying and converting files, often used for creating raw disk images                   |
| [Click]()     | dc3dd             | An enhanced version of dd with additional features for forensic imaging, including hashing and logging                   |
| [Click]()     | ddrescue          | A data recovery tool that efficiently copies data from damaged drives, attempting to rescue as much data as possible     |
| [Click]()     | FTK Imager        | A GUI-based tool for creating forensic images, widely used for its ease of use and comprehensive features                   |
| [Click]()     | Guymager          | A GUI-based forensic imaging tool that supports various image formats and provides detailed logs                   |
| [Click]()     | EWF Tools         | Tools for creating and handling Expert Witness Format (EWF) images, often used in digital forensics                   |
| [Click]()     | KAPE              | live data acquisition and analysis tool                   |

## Windows Artifact (i.e. Timestamp) Analysis Tool
| Download      | Registry Tools    | Description
| ------------- | ----------------  | ------------------------------------------------------------------------------------------------------ |
| [Click]()     | UserAssist        | limitations: It only loads one hive at a time, and it can't take the transaction logs into account.                   |
| [Click]()     | ShimCache         | It can load multiple hives simultaneously                   |
| [Click]()     | AmCache           | It is a utility that takes a registry hive as input and outputs a report     |
| [Click]()     | BAM/DAM           | It is a utility that takes a registry hive as input and outputs a report     |
